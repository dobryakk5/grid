Имена трейдеров —

Наш сервер получает от FOMO 430 на любой токен, а ваш браузер — нет. Поэтому имена собираются во вкладке fomo.family: отсюда, с localhost, тот же запрос браузер режет по CORS.

  1. Здесь (эта страница) — «Скопировать код».
  2. Перейдите на fomo.family, залогиньтесь, откройте F12 → Console именно там, вставьте код, Enter.
  3. Он спросит Bearer-токен. Взять на той же вкладке: F12 → Network → любой запрос к prod-api.fomo.family → Request Headers → Authorization, скопировать часть после Bearer .
  4. Код обойдёт монеты и положит JSON в буфер. Вернитесь сюда и вставьте его в поле ниже.
