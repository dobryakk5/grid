{# Shared login, included by every page. The API requires a token; the pages call `fetch` directly, in a dozen places, including one call assembled as a string at runtime. Patching each call site would leave the next one to be written unprotected, so this wraps `fetch` once: any same-origin /api/ request carries the bearer, and a 401 opens the password dialog and retries instead of surfacing as an error. That retry is also what stops the browser's basic-auth prompt storm. Every unauthenticated API call used to come back 401, and a page that fires three of them produced three prompts. #}
